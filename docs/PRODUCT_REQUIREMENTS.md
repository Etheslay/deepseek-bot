# 产品需求基线

日期：2026-10-22。状态：供开发评审的设计稿。用户确认的约束与团队建议如下区分。

## 1. 产品定位

DeepSeek Bot 是本地桌面上的机器人工作台。用户为不同机器人设置职责、选择工作目录和工具，再以聊天或工作流组织它们完成任务。核心体验参考 Grok Bot，界面素材、品牌和产品文案独立设计。

用户已确定：基于 DeepSeek Harness；轻量桌面；任务执行和应用数据在本机；允许 DeepSeek API；不使用云电脑；双人 Git Flow。

建议首发目标为 Windows 11 x64、简体中文、单机单用户。macOS / Linux 的适配独立验收。首发平台是根据当前开发环境提出的建议，尚非用户明确指定的平台要求。

## 2. 目标用户与主路径

目标用户能够填写自己的 API Key，希望用多个有明确职责的机器人处理本地资料、编程和重复任务，无需管理云服务器。

主路径：安装 → 设置 API 与工作目录 → 创建机器人 → 单次对话验证 → 添加其他机器人 → 创建工作流 → 执行并查看日志 → 人工审批需要授权的步骤 → 查看产物 → 保存为模板并重复运行。

首个贯通场景：研究机器人读取指定样例目录，整理机器人汇总内容，审阅机器人给出检查意见；用户批准后将报告写入指定输出目录。三者输入输出、执行状态、工具动作与产物可追溯。

## 4. 首个可发行版本 v0.1.0

| 编号 | 需求 | 验收条件 |
| --- | --- | --- |
| FR-01 | 设置与接入 | API Key 安全保存；可测试连接；错误可理解；Key 不出现在日志或界面回读中 |
| FR-02 | 机器人管理 | 创建、编辑、复制、归档；重启后保留；归档不破坏历史工作流版本 |
| FR-03 | 会话 | 流式响应、可见工具状态、取消、失败原因、会话重开与历史回放 |
| FR-04 | 工作流编辑 | 新建/保存/复制流程；选择机器人；配置依赖；拒绝环和缺失输入；模板导入导出 |
| FR-05 | 工作流执行 | 支持顺序与独立分支并发；状态明确；输入输出按节点隔离；并发默认最多 2 个模型任务 |
| FR-06 | 审批 | 必须在实际副作用前拦截；展示精确参数；拒绝后不执行；重启后旧审批不能直接重放 |
| FR-07 | 运行历史 | 运行及节点状态、版本快照、时间和产物；可定位 Harness 会话；重启后恢复查看 |
| FR-08 | 本地调度 | 时区明确；应用打开或驻留托盘时触发；休眠错过任务标记 missed，不批量静默补跑 |
| FR-09 | 数据管理 | 可查看数据位置、备份与恢复；备份默认排除密钥；恢复前校验版本并保留原数据 |
| FR-10 | 打包交付 | 干净目标机器可安装、启动、使用、升级与卸载；无需用户另装开发工具 |

节点首版支持机器人任务与人工确认，不支持任意内嵌脚本节点。节点模板使用显式引用和字段映射，不执行模板中的代码。重试范围和终止策略见接口契约。

## 5. 本地运行边界

- 本地保存不代表离线推理。用户发出的指令、选择的资料和必要工具结果可传给配置的模型服务。
- 关闭窗口可选择驻留托盘或退出。真正退出、关机、休眠时不保证执行；界面不能显示“云端仍在运行”。
- 未恢复的运行标记为 interrupted；非幂等动作不得自动重做，需用户决定。
- 机器人共享同一台电脑资源，必须有队列、限流和工具权限；工作目录不是操作系统级隔离。
- 不强制产品账户登录，不将产品数据自动同步到自建服务。原示例中的 login / payment 仅是分支命名示例，不自动生成登录/支付需求。

## 6. 轻量化目标（建议预算，尚未实测）

基准机：Windows 11 x64、4 核 CPU、16 GB RAM、SSD；运行时模型推理由 API 提供。冷启动到可交互 p95 ≤ 5 秒（10 次）；空闲 60 秒后进程树总内存 ≤ 350 MB；空闲 CPU 平均 ≤ 2%；离线安装包 ≤ 200 MB（不含可选浏览器、模型权重和扩展工具）。

报告必须包含硬件、系统、进程树范围、构建 SHA 和原始结果。Electron 与上游依赖可能超出预算，D01 技术验证后可通过 ADR 调整预算或改变方案；未测量不得宣称达标。

## 7. 完成标准

v0.1.0 必须通过全部 FR-01 至 FR-10、[测试矩阵](TESTING.md)、[发布门槛](RELEASE.md)。有演示界面、开发服务器可运行或打包命令返回成功，都不能单独代表可发行。

## 8. 阶段二需求（v0.2）

阶段二在 v0.1 的本地工作台之上补齐“聊天驱动创建 + 平台能力”，仍坚持单机、无云账户、无遥测。任务与分支见 [开发计划](DEVELOPMENT_PLAN.md) §6，架构与边界见 [智能体平台](AGENT_PLATFORM.md)。
