## 1. 交付行为

桌面记忆面板上的「导入知识」打开系统文件对话框，一次选一个文件。渲染进程不能传入路径，模型工具目录里也没有导入工具。

计划只写了知识导入要有大小和格式上限，没有写明字节数。本片采用固定上限，不能在设置里修改：

- 格式只接受 `.txt` 和 `.md`，大小写不限。
- 文件不超过 16 KiB（16384 字节）。超过就不读取正文。
- 必须是 UTF-8。正文去掉首尾空白和可选的 BOM 后，须为 1–4000 字，与一条现有记忆相同。
- 任一上限不满足时不调用 `memory.write`。
- 通过后用既有 `memory.write` 写成当前 bot 的一条记忆。`memory.list`、`memory.search` 和 `memory.delete` 的隔离规则不变。

没有新的知识表、向量检索、保留策略或 D19 内容。协议仍为 0.3，没有新迁移。
