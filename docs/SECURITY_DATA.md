# 本地数据、密钥与工具权限

状态：设计要求，尚未实现和验证。

## 1. 数据边界

| 数据 | 存放与流向 | 规则 |
| --- | --- | --- |
| Bot / Workflow / Schedule / Run 元数据 | 本地应用数据库 | 事务写入、版本迁移、用户可备份/删除 |
| Harness 会话和模型上下文 | 专属本地 Harness home；必要内容发往 DeepSeek API | 原生日志与版本机制，不复制明文凭据 |
| 工具输入/输出与文件产物 | 用户授权工作目录或应用产物目录 | 只读取完成任务所需内容，产物可定位 |
| API Key | 系统凭据库或操作系统加密保护的存储 | 不放数据库明文、仓库、renderer、日志或普通导出 |
| 日志和诊断 | 本地滚动日志 | 默认保留 7 天且总量 ≤ 100 MB；可配置，超限轮换 |
| 缓存 | 本地可重建目录 | 可清理，不混入唯一用户文件 |

本地保存不代表 API 提供方不处理请求。首次接入说明请求流向，用户选择目录和工具；外部 MCP/网站可能产生独立网络请求，启用时展示服务目标与权限。

## 2. 计划目录

```text
<系统应用数据>/DeepSeekBot/
  app.sqlite           应用元数据
  harness/             本应用独立 Harness home
  artifacts/           运行产物
  backups/             用户创建的备份（可更改位置）
  logs/                脱敏轮换日志
  cache/               可清理缓存
```

目录位置由平台 API 解析，不硬编码用户名。安装目录不能用于存储可变用户数据。用户工作目录保持原位置，权限与应用数据根分开。

## 3. 执行权限

默认最小授权。用户显式选择工作区；读、写、执行、网络和外部服务权限分开。危险动作必须在后端执行前拦截，可显示具体将修改的路径/命令/目标。审批适用精确动作和运行，不做无限期全局通行证。

路径必须规范化并处理符号链接、junction、UNC、大小写和检查后路径替换。仅检查 `startsWith(workspace)` 不够；禁止前端传任意绝对路径并直接执行。Shell 工具可绕过应用文件 API，必须有可验证的操作系统约束或停用该能力；不能将逻辑目录限制称为完整沙箱。

对外发送消息、购买、删除文件和广泛系统操作，除用户明确授权的流程外必须请求确认。首发不承诺任意桌面控制；后续引入时需要单一操作锁、用户中断按钮与权限提示。

插件与 Skills 是能力扩展，同时也是代码/指令来源。固定来源和版本，展示权限，显式安装/启用；项目文件或模型输出不能自行扩大授权。预览 HTML 等产物时禁用主动脚本及任意本机接口。

## 4. 网络与进程

Host 不绑定 0.0.0.0，不默认开局域网远控。优先私有 IPC；回环 HTTP 也需要认证、来源校验和防止未授权网页访问。日志不包含 Host 认证令牌。

取消或退出仅结束应用拥有的进程树；不停止用户其他程序。重启后未知副作用标记 interrupted，不无条件重放。

## 5. 备份、恢复、删除

备份先暂停任务并刷新应用数据库与 Harness 日志，生成同一时间点的清单和校验值；包含版本和文件哈希，默认排除 API Key、浏览器登录状态与缓存。备份含聊天内容，界面必须提醒其敏感性。

恢复先验证校验值、大小上限、路径与 schemaVersion；拒绝压缩路径穿越和未来版本，保留当前数据副本，恢复失败可回退。恢复后的工具授权与凭据须重新确认，不能通过导入模板静默获得权限。

删除机器人不自动删除用户工作区文件。历史删除明确影响范围；卸载默认保留用户数据，提供独立确认的清除方式。数据库删除和 SSD 文件删除不保证物理介质不可恢复，不宣称“绝对擦除”。

## 6. 发布前验证

密钥泄露、越权写文件、未经批准执行、数据损坏是发布阻断。测试场景见 QA-07/08/11/12/14；许可与依赖审查跟随每次上游升级，不把本项目自动宣称为 DeepSeek 官方产品。
