# 本地数据、密钥与工具权限

状态：设计要求。数据边界与存储层（SQLite 元数据、目录布局、凭据密文仓、备份/恢复）自 D04 起在 `packages/storage` 实现；工具权限拦截（§3）自 D08 起在 `packages/runtime/src/permissions/` 实现后端检查、路径约束、一次性审批与 MCP 授权（shell 的操作系统级约束与进程边界（§4）仍属适配层后续任务，尚未实现）。

## 1. 数据边界

| 数据 | 存放与流向 | 规则 |
| --- | --- | --- |
| Bot / Workflow / Schedule / Run 元数据 | 本地应用数据库 | 事务写入、版本迁移、用户可备份/删除 |
| Harness 会话和模型上下文 | 专属本地 Harness home；必要内容发往 DeepSeek API | 原生日志与版本机制，不复制明文凭据 |
| 工具输入/输出与文件产物 | 用户授权工作目录或应用产物目录 | 只读取完成任务所需内容，产物可定位 |
| API Key | 系统凭据库或操作系统加密保护的存储 | 不放数据库明文、仓库、renderer、日志或普通导出 |
| 日志和诊断 | 本地滚动日志 | 默认保留 7 天且总量 ≤ 100 MB；可配置，超限轮换 |
| 缓存 | 本地可重建目录 | 可清理，不混入唯一用户文件 |

本地保存不代表 API 提供方不处理请求。首次接入说明请求流向，用户选择目录和工具；外部 MCP/网站可能产生独立网络请求，启用时展示服务目标与权限。

## 2. 计划目录

```text
<系统应用数据>/DeepSeekBot/
  app.sqlite           应用元数据
  harness/             本应用独立 Harness home
  artifacts/           运行产物
  backups/             用户创建的备份（可更改位置）与恢复前暂存
  logs/                脱敏轮换日志
  cache/               可清理缓存
  credentials/         API Key 密文 blob（safeStorage 加密，数据库只存 cred:<uuid> 引用）
  imports/chrome/      Chrome 书签导入结果（bookmarks.json / bookmarks.md，用户可一键删除）
  screen-outputs/      指定窗口的 PNG、预览 JPEG、OCR 文本和清单；不进入元数据备份
  device-outputs/      已执行的指针/按键 JSON 与清单；不进入元数据备份
```

目录位置由平台 API 解析，不硬编码用户名。安装目录不能用于存储可变用户数据。用户工作目录保持原位置，权限与应用数据根分开。凭据密文绑定桌面应用身份（Windows safeStorage 以应用 userData 为熵，D04 实测）；应用身份或机器变化后密文不可解密，走失败路径并要求重新录入，不做明文降级。

## 3. 执行权限

默认最小授权。用户显式选择工作区；读、写、执行、网络和外部服务权限分开。危险动作必须在后端执行前拦截，可显示具体将修改的路径/命令/目标。审批适用精确动作和运行，不做无限期全局通行证。

路径必须规范化并处理符号链接、junction、UNC、大小写和检查后路径替换。仅检查 `startsWith(workspace)` 不够；禁止前端传任意绝对路径并直接执行。Shell 工具可绕过应用文件 API，必须有可验证的操作系统约束或停用该能力；不能将逻辑目录限制称为完整沙箱。

对外发送消息、购买、删除文件和广泛系统操作，除用户明确授权的流程外必须请求确认。首发不承诺任意桌面控制；后续引入时需要单一操作锁、用户中断按钮与权限提示。

插件与 Skills 是能力扩展，同时也是代码/指令来源。固定来源和版本，展示权限，显式安装/启用；项目文件或模型输出不能自行扩大授权。预览 HTML 等产物时禁用主动脚本及任意本机接口。

## 4. 网络与进程

Host 不绑定 0.0.0.0，不默认开局域网远控。优先私有 IPC；回环 HTTP 也需要认证、来源校验和防止未授权网页访问。日志不包含 Host 认证令牌。

取消或退出仅结束应用拥有的进程树；不停止用户其他程序。重启后未知副作用标记 interrupted，不无条件重放。

## 5. 桌面系统集成（D22）

| 能力 | 读取/写入范围 | 边界 |
| --- | --- | --- |
| Chrome 书签导入 | 只读 `<Chrome User Data>/<Profile>/Bookmarks` 与 `Local State`（取配置显示名） | **不读 Cookie、登录态、密码、支付信息与浏览历史**；只保留 `http(s)` 链接并按 URL 去重，单文件 >8 MiB 拒绝，导入上限 5000 条；profile 目录名必须是 `Default`/`Profile N` 形态的简单名字，拒绝分隔符与 `..`，解析后仍校验落在 User Data 之内；结果只写本机数据根 `imports/chrome/`，无网络请求，可在设置内一键删除 |
| 系统通知 | 主进程 `Notification`，内容为 Bot 名 + 事件类型（回复完成 / 等待审批 / 错过定时） | 不携带消息正文与文件路径；默认仅在窗口不在前台时提醒，可按 Bot 静音；通知不写日志、不上报，系统无通知通道时如实返回不可用 |
| 托盘 | 渲染层推送的 Bot 名、状态、未读标记与 32px PNG 头像 data URL | 主进程不读数据库；payload 有条目上限（50）、名字长度与图标类型/大小校验，非 PNG data URL 直接拒绝；点击托盘项只让主窗口显示并聚焦对应会话 |
| 界面语言 | 偏好写入 renderer 的 localStorage；主进程只接收 `system|zh|en` 三值 | 语言不影响任何存储数据值（能力 id、Bot 名、语气指令等保持原值），只影响显示；发给模型的提示文本不做翻译，避免静默改变模型行为 |

## 6. 备份、恢复、删除

备份先暂停任务并刷新应用数据库与 Harness 日志，生成同一时间点的清单和校验值；包含版本和文件哈希，默认排除 API Key、浏览器登录状态与缓存。备份含聊天内容，界面必须提醒其敏感性。

恢复先验证校验值、大小上限、路径与 schemaVersion；拒绝压缩路径穿越和未来版本，保留当前数据副本，恢复失败可回退。恢复后的工具授权与凭据须重新确认，不能通过导入模板静默获得权限。

界面接线（D24 收尾切片）：设置 → 保险库提供备份创建、备份列表与恢复入口。备份列表由桌面主进程只读各备份目录的 `manifest.json` 摘要（`backups:list` 通道，不经 Host 契约）；备份含聊天内容的敏感提醒与"不含产物文件/版本快照/API Key"的边界说明固定显示在分区里。恢复必须逐次确认；成功后主进程重启 Host 子进程并重载渲染层，恢复期间旧 Host 的调用快速失败；恢复失败（有活动运行、校验不符、未来版本等）原样展示稳定错误码。恢复后凭据密文不在备份内，界面提示可能需要重新输入 Key。硬件加速开关保存在 Electron userData（shell 级偏好，非数据根），改动需重启应用生效。

`screen-outputs/` 不在元数据备份里，也不在可选的 artifacts 树里。恢复备份不会带回截图或 OCR 文本，也不会恢复只保存在 Host 进程里的窗口选择。文件已经不在时，读取该结果会报不可用。设置页删除只接受该 bot 清单中的一条，不接受任意路径。

`device-outputs/` 同样不在元数据备份里，也不在可选的 artifacts 树里。一次已执行的指针或按键留下该 bot 目录下的 JSON 和清单。恢复备份不会带回这些产物。清单或产物被换成符号链接、或文件已经不在时，列出结果会拒绝，而不是跟着链接读到目录外面。响应不返回文件系统路径。

删除机器人不自动删除用户工作区文件。历史删除明确影响范围；卸载默认保留用户数据，提供独立确认的清除方式。数据库删除和 SSD 文件删除不保证物理介质不可恢复，不宣称“绝对擦除”。

## 6. 发布前验证

密钥泄露、越权写文件、未经批准执行、数据损坏是发布阻断。测试场景见 QA-07/08/11/12/14；许可与依赖审查跟随每次上游升级，不把本项目自动宣称为 DeepSeek 官方产品。
